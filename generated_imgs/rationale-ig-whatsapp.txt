RATIONALE — Instagram Post: Alerta WhatsApp VBS Malware
=========================================================
Minery Report | Abril 2026

CONTEXTO
--------
Microsoft alertó el 1 de abril de 2026 sobre una campaña activa que
distribuye malware VBS (Visual Basic Script) a través de mensajes de
WhatsApp. Los scripts inician una cadena de infección multi-etapa que
usa utilidades legítimas de Windows renombradas y payloads alojados en
servicios cloud confiables (AWS, Tencent Cloud, Backblaze B2).

Fuente: The Hacker News, 01/04/2026.

TRADUCCIÓN GRID → PROMPT
------------------------
El grid NO crea paneles visuales. Se traduce a instrucciones de
composición espacial en lenguaje natural:

  - "In the top-left corner, seamlessly integrated..."  ← [header, col 1]
  - "In the center, a large cracked WhatsApp icon..."   ← [centro visual]
  - "The bottom 20% gradually darkens to black..."      ← [headline + footer]

La clave es usar palabras como "seamlessly", "naturally", "one continuous
scene" para evitar que el modelo genere un collage de paneles separados.

APRENDIZAJES PARA EL SKILL
---------------------------
1. El grid debe guiar composición, NO crear paneles. El prompt necesita
   instrucciones explícitas anti-collage.

2. ⚠️ REGLA CRÍTICA — REFERENCIAS DE ARCHIVO OBLIGATORIAS PARA LOGOS:
   Es IMPOSIBLE replicar un logo o ilustración de marca solo con
   descripción textual. El modelo siempre generará una aproximación,
   nunca una copia exacta. La descripción "4 círculos dorados en un
   diamante conectados por curvas" produjo un símbolo de infinito,
   luego un patrón de 4 puntos sin curvas, etc.

   SOLUCIÓN OBLIGATORIA: el skill DEBE exigir un archivo de referencia
   (PNG/SVG) para cualquier elemento de marca. El flujo correcto es:

     a) generate_image → genera la escena con un placeholder aproximado
     b) edit_image + referenceImages:["/ruta/al/logo.png"] → reemplaza
        el placeholder por el logo real usando la referencia de archivo

   Esto aplica a: logos, isologos, iconos de marca, ilustraciones
   propietarias, mascotas, cualquier elemento visual que deba ser
   exacto y reconocible.

   Sin referencia de archivo → el resultado SIEMPRE será incorrecto
   para elementos de identidad de marca.

3. Los colores de marca deben especificarse como hex + nombre descriptivo
   Y reforzarse con "NO navy blue", "NO other colors" para evitar
   desviaciones del modelo. Especial atención a colores dentro de
   elementos del logo — el modelo tiende a insertar navy blue en
   fondos oscuros incluso cuando se especifica negro puro.

4. La iteración edit_image + continue_editing permite correcciones
   quirúrgicas sin regenerar toda la imagen.

5. El skill debe incluir un paso de validación de marca: antes de dar
   por terminada una imagen con elementos de identidad, verificar
   visualmente que el logo coincide con la referencia y que los
   colores no se han desviado.
